Palma Verde — a 2D top-down open-world crime game across three cities (Solmar Bay, Neon Harbor, Palma Verde): explore on foot and by car, steal cars, outrun the police as your wanted level rises, and complete a 6-mission story chain.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
# then serve game/ locally, e.g. `python3 -m http.server` from inside game/,
# and open http://localhost:8000 in a desktop browser
```
